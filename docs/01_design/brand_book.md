# Brand Book

Version: 1.0  
Status: Approved  
Project: Project Hifz Rehberi  
Product: Hifz Rehberi

## 1. Brand Identity

Hifz Rehberi is a calm, trustworthy and elegant digital companion for
traditional Qur'an memorization.

The application exists to support, not replace, the relationship between:

- the student,
- the teacher,
- the Qur'an.

Technology remains in the background.

The Qur'an remains at the center of attention.

## 2. Design Philosophy

Every design decision should answer one central question:

> Does this help the user memorize the Qur'an?

If the answer is no, the element should be simplified, redesigned or
removed.

Design serves memorization.

It never competes with it.

## 3. Core Brand Values

The visual identity must communicate:

- respect,
- calmness,
- trust,
- simplicity,
- spirituality,
- consistency,
- excellence.

## 4. Visual Character

The application should feel:

- premium,
- modern but timeless,
- elegant but minimal,
- warm but professional,
- traditional but innovative,
- spiritually respectful.

The application must never feel:

- playful,
- flashy,
- noisy,
- crowded,
- childish,
- visually overwhelming.

## 5. Core Color Identity

The binding brand colors are:

- Emerald Green
- Turquoise
- Gold
- Ivory

### Emerald Green

Emerald represents:

- trust,
- tradition,
- stability,
- spiritual depth.

It is the primary brand color.

### Turquoise

Turquoise represents:

- clarity,
- freshness,
- balance,
- calm technology.

It is used as a secondary and supportive color.

### Gold

Gold represents:

- value,
- dignity,
- achievement,
- sacred emphasis.

Gold must be used sparingly.

It is reserved for:

- highlights,
- milestones,
- premium details,
- selected decorative elements.

### Ivory

Ivory represents:

- calmness,
- warmth,
- readability,
- spaciousness.

It is the preferred light background color.

## 6. Typography

Typography must prioritize:

- readability,
- calmness,
- hierarchy,
- consistency.

Interface typography should use:

- generous line spacing,
- clear headings,
- comfortable body text,
- high contrast,
- restrained font weights.

Arabic Qur'an text always receives visual priority over interface text.

The Mushaf script must never be visually compressed, crowded or treated as
ordinary body text.

## 7. Logo

The approved Hifz Rehberi logo is the only official logo.

The logo may not be:

- redrawn,
- distorted,
- recolored without approval,
- replaced by an AI-generated variation,
- stretched,
- cropped,
- decorated with additional symbols.

The logo should be visible but never dominate the learning experience.

Detailed usage rules are defined in:

`docs/01_design/logo_reference.md`

## 8. Layout Philosophy

Interfaces should feel spacious and calm.

Use:

- generous whitespace,
- consistent spacing,
- clear visual hierarchy,
- rounded surfaces,
- subtle depth,
- limited simultaneous actions.

Avoid:

- crowded screens,
- unnecessary separators,
- excessive decoration,
- too many competing cards,
- dense text blocks.

## 9. Components

### Cards

Cards should use:

- soft corners,
- subtle elevation,
- calm backgrounds,
- clear internal spacing,
- minimal borders.

### Buttons

Buttons should be:

- easy to understand,
- large enough for comfortable touch,
- visually consistent,
- limited to clear actions.

Primary actions receive stronger emphasis.

Secondary actions remain understated.

### Icons

Icons should be:

- simple,
- consistent,
- recognizable,
- restrained.

Outlined icons are preferred where appropriate.

Decorative icons must not compete with functional content.

## 10. Dashboard

The dashboard is the emotional and functional home of the application.

It should immediately answer:

- What should I memorize today?
- What should I repeat today?
- What is my current progress?
- What requires my attention?

The dashboard should provide structure without creating pressure.

Motivational content should remain subtle and meaningful.

Detailed dashboard rules are defined in:

`docs/01_design/dashboard_reference.md`

## 11. Reading Mode

Reading mode is the most sensitive and focused screen of the application.

The Mushaf must receive absolute visual priority.

Interface elements should remain:

- discreet,
- calm,
- easy to hide,
- visually secondary.

Nothing should unnecessarily distract from:

- reading,
- recitation,
- memorization,
- reflection.

Detailed rules are defined in:

`docs/01_design/reading_mode_reference.md`

## 12. Onboarding

Onboarding should be:

- short,
- clear,
- friendly,
- respectful,
- easy to complete.

The user should not be overwhelmed with too many questions.

The application should quickly understand the user's role and learning
context.

Detailed rules are defined in:

`docs/01_design/onboarding_reference.md`

## 13. Motion

Animations should be:

- smooth,
- restrained,
- purposeful,
- calm.

Animations must never be:

- exaggerated,
- playful,
- distracting,
- unnecessarily long.

Motion should support orientation and feedback.

It should never become entertainment.

## 14. Accessibility

The application should support:

- readable contrast,
- large touch targets,
- scalable text,
- clear navigation,
- consistent interaction patterns,
- light and dark themes where appropriate.

Accessibility must not be treated as an optional visual enhancement.

It is part of product quality.

## 15. Language of Documentation

Technical and internal project documentation is written in English.

User-facing application content is multilingual.

Initial product languages are:

- German,
- Turkish.

Additional languages may be introduced later.

## 16. Binding Design Rule

Every interface element must support Qur'an memorization.

If an element distracts from the learning process, it must be simplified,
redesigned or removed.

Every screen must remain:

- calm,
- elegant,
- focused,
- consistent,
- respectful,
- easy to understand,
- supportive of memorization.

## 17. Change Control

This Brand Book is frozen as version 1.0.

Future changes require:

1. an explicit proposal,
2. CEO approval,
3. a version update,
4. a dedicated Git commit.
