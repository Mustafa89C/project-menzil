# AI Agent Rules

Version: 1.0  
Status: Approved

These rules apply to every AI agent working on Project Hifz Rehberi.

## Required reading order

1. Project Constitution
2. Product Foundation
3. Brand Book and relevant design references
4. Architecture documentation
5. Current sprint brief
6. Agent-specific instructions

## Mandatory rules

- Do not expand sprint scope without explicit approval.
- Do not make independent product or branding decisions.
- Do not replace approved references with newly invented designs.
- Only modify files included in the approved implementation scope.
- Preserve existing working behavior unless the sprint requires a change.
- Review all changes before proposing a commit.
- Run relevant analysis and tests.
- Report uncertainties, risks and incomplete work honestly.
- The CEO retains final product and design approval.
